# txlnk_adtech_sdk

Flutter plugin for TixLnk deep links and attribution: first-open match by an
opaque click token, Universal Links / App Links, Android Play Install Referrer,
iOS App Clip handoff through an App Group, and conversion events.

No device fingerprinting: the SDK does not collect device signals.

Integration guide, server-side flow and platform setup:
https://github.com/Forge-Founders/tixlnk-sdk#readme
